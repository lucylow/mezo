# Vibe Code Prompt: Mezo Passport Integration for Auto‑Compounder Vault

**Repository:** `lucylow/mezo`  
**Target Branch:** `feat/mezo-passport`  
**Goal:** Implement complete, production‑ready **Mezo Passport** wallet connectivity for the Auto‑Compounder Vault. Mezo Passport is the official wallet‑connection library built on **RainbowKit** that adds native **Bitcoin wallet** support (Xverse, Unisat, OKX) alongside standard **EVM wallets** (MetaMask, WalletConnect). This integration satisfies the hackathon's mandatory **30% Mezo Integration** judging requirement and provides a seamless "login with Bitcoin" experience.

**Context:** The repository currently uses basic wagmi + RainbowKit configuration. This prompt upgrades the entire wallet‑connection layer to Mezo Passport's `getConfig` method, adds Bitcoin‑account hooks (`useBitcoinAccount`, `useSendBitcoin`), implements a custom Mezo‑branded RainbowKit theme, provides robust error handling for wallet connection failures, and supports both BTC and EVM signing/transaction operations.


## 1. Architecture Overview

Mezo Passport works by **"masquerading" Bitcoin wallets as EVM‑compatible wallets**. Under the hood, each Bitcoin wallet (Xverse, Unisat, OKX) has a **backing smart account** on the Mezo Matsnet chain. This smart account validates signatures from the Bitcoin wallet and issues EVM transactions on the user's behalf. Signing operations (like authorizing transactions) are routed to the actual Bitcoin wallet, while EVM operations (reading data, interacting with smart contracts) flow through the backing provider. This design lets users connect with a Bitcoin wallet and interact with EVM‑compatible dApps **without switching wallets or providers manually**.

The integration spans five layers:

1. **Configuration Layer** – `getConfig()` from `@mezo-org/passport` wraps RainbowKit's `createDefaultConfig`, adding Bitcoin wallet connectors.
2. **Provider Layer** – `WagmiProvider` → `QueryClientProvider` → `RainbowKitProvider` wraps the entire app.
3. **Hook Layer** – Custom React hooks: `useWalletConnection`, `useBitcoinAccount`, `useNetworkStatus`, `useSendBitcoin`.
4. **Component Layer** – `ConnectButton`, `AccountModal`, `NetworkSwitcher`, `BitcoinBalance`.
5. **Utility Layer** – Error parsers, address formatters, theme constants.

### 4.2. Wagmi Configuration with Mezo Passport (`lib/wagmi/config.ts`)

This is the central configuration file. Mezo Passport's `getConfig` method returns a default configuration for Mezo Matsnet and must be passed to `WagmiProvider`. You can pass the same configuration options to `getConfig` as you would to `createDefaultConfig` from RainbowKit.

By default, the library supports **Unisat, OKX, and Xverse** Bitcoin wallets. You can customize which Bitcoin wallets to include via the `bitcoinWallets` property.

```typescript
// lib/wagmi/config.ts
import { getConfig, mezoTestnet, mezoMainnet } from '@mezo-org/passport';
import { http } from 'wagmi';
import { type Config } from 'wagmi';

const projectId = process.env.NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID;

if (!projectId) {
  throw new Error(
    'NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID is required. ' +
    'Get one at https://cloud.walletconnect.com/'
  );
}

/**
 * Creates the wagmi configuration with Mezo Passport.
 *
 * getConfig() returns a default configuration for Mezo Matsnet
 * that includes Bitcoin wallet support (Xverse, Unisat, OKX)
 * alongside standard EVM wallets (MetaMask, WalletConnect).
 *
 * You can pass the same options as RainbowKit's createDefaultConfig.
 */
export const config: Config = getConfig({
  appName: 'veMEZO Auto-Compounder',
  projectId,
  chains: [mezoTestnet, mezoMainnet],
  transports: {
    [mezoTestnet.id]: http(),
    [mezoMainnet.id]: http(),
  },
  ssr: true, // Enable SSR compatibility
}) as Config;
```

**Customizing Bitcoin Wallets:**

If you want to limit Bitcoin wallet support (e.g., only Unisat), use the `bitcoinWallets` property:

```typescript
// lib/wagmi/config-custom.ts (alternative — only Unisat)
import { getConfig, unisatWallet, mezoTestnet } from '@mezo-org/passport';
import { http } from 'wagmi';

const customBitcoinWallets = [
  {
    groupName: 'Bitcoin Wallets',
    wallets: [unisatWallet],
  },
];

export const customConfig = getConfig({
  appName: 'veMEZO Auto-Compounder',
  projectId: process.env.NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID!,
  chains: [mezoTestnet],
  transports: {
    [mezoTestnet.id]: http(),
  },
  bitcoinWallets: customBitcoinWallets,
});
```

## 5. Web3 Provider Hierarchy

### 5.1. `providers/Web3Provider.tsx`

Wraps the entire application with `WagmiProvider`, `QueryClientProvider`, and `RainbowKitProvider`. This is the standard integration pattern.

```tsx
// providers/Web3Provider.tsx
'use client';

import { WagmiProvider } from 'wagmi';
import { RainbowKitProvider } from '@rainbow-me/rainbowkit';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { useState, type ReactNode } from 'react';
import { config } from '@/lib/wagmi/config';
import { mezoTheme } from '@/lib/wagmi/theme';
import { mezoTestnet } from '@mezo-org/passport';
import { Toaster } from 'sonner';
import '@rainbow-me/rainbowkit/styles.css';

interface Web3ProviderProps {
  children: ReactNode;
}

export function Web3Provider({ children }: Web3ProviderProps) {
  const [queryClient] = useState(
    () =>
      new QueryClient({
        defaultOptions: {
          queries: {
            staleTime: 30_000,       // 30 seconds
            gcTime: 5 * 60_000,      // 5 minutes
            refetchOnWindowFocus: false,
            retry: 1,
          },
          mutations: {
            retry: 1,
          },
        },
      })
  );

  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        <RainbowKitProvider
          theme={mezoTheme}
          initialChain={mezoTestnet}
          modalSize="compact"
          appInfo={{
            appName: 'veMEZO Auto-Compounder',
            learnMoreUrl: 'https://mezo.org/docs',
          }}
        >
          {children}
          <Toaster
            position="top-right"
            theme="dark"
            toastOptions={{
              style: {
                background: '#0A0B0D',
                border: '1px solid rgba(255, 255, 255, 0.08)',
                color: '#FFFFFF',
              },
            }}
          />
        </RainbowKitProvider>
      </QueryClientProvider>
    </WagmiProvider>
  );
}
```

## 6. Custom React Hooks

### 6.1. `useWalletConnection` – Connection State & Actions

Provides a unified interface for connecting, disconnecting, and switching chains. Uses `useConnect` and `useDisconnect` from wagmi.

```typescript
// hooks/useWalletConnection.ts
'use client';

import { useAccount, useConnect, useDisconnect, useSwitchChain, useChainId } from 'wagmi';
import { useCallback, useMemo } from 'react';
import { toast } from 'sonner';
import { mezoTestnet } from '@mezo-org/passport';

export interface WalletConnectionState {
  isConnected: boolean;
  isConnecting: boolean;
  isReconnecting: boolean;
  isSwitchingNetwork: boolean;
  address: `0x${string}` | undefined;
  chainId: number | undefined;
  connectorName: string | undefined;
}

export interface WalletConnectionActions {
  connect: () => Promise<void>;
  disconnect: () => Promise<void>;
  switchToMezo: () => Promise<void>;
}

export function useWalletConnection(): WalletConnectionState & WalletConnectionActions {
  const { address, isConnected, chainId, connector } = useAccount();
  const { connectAsync, connectors, isPending: isConnecting } = useConnect();
  const { disconnectAsync } = useDisconnect();
  const { switchChainAsync, isPending: isSwitchingNetwork } = useSwitchChain();

  /**
   * Connect to the first available connector.
   * Mezo Passport surfaces Bitcoin wallets alongside EVM wallets.
   */
  const connect = useCallback(async () => {
    try {
      // Find the first ready connector
      const connector = connectors.find((c) => c.ready) || connectors[0];
      if (!connector) {
        toast.error('No wallet connector available. Please install a supported wallet.');
        return;
      }

      await connectAsync({
        connector,
        chainId: mezoTestnet.id,
      });
      toast.success('Wallet connected successfully');
    } catch (error: any) {
      if (error?.message?.includes('rejected') || error?.message?.includes('User rejected')) {
        toast.error('Connection cancelled.');
      } else if (error?.message?.includes('Connector not found')) {
        toast.error('Wallet not installed. Please install Xverse, Unisat, OKX, or MetaMask.');
      } else {
        toast.error(`Connection failed: ${error?.message || 'Unknown error'}`);
      }
      throw error;
    }
  }, [connectAsync, connectors]);

  const disconnect = useCallback(async () => {
    try {
      await disconnectAsync();
      toast.success('Wallet disconnected');
    } catch (error: any) {
      toast.error(`Disconnect failed: ${error?.message || 'Unknown error'}`);
      throw error;
    }
  }, [disconnectAsync]);

  const switchToMezo = useCallback(async () => {
    try {
      await switchChainAsync({ chainId: mezoTestnet.id });
      toast.success('Switched to Mezo Testnet');
    } catch (error: any) {
      if (error?.message?.includes('rejected')) {
        toast.error('Network switch cancelled.');
      } else {
        toast.error(`Network switch failed: ${error?.message || 'Unknown error'}`);
      }
      throw error;
    }
  }, [switchChainAsync]);

  const isReconnecting = useMemo(() => isConnecting && !isConnected, [isConnecting, isConnected]);

  return {
    isConnected,
    isConnecting,
    isReconnecting,
    isSwitchingNetwork,
    address,
    chainId,
    connectorName: connector?.name,
    connect,
    disconnect,
    switchToMezo,
  };
}
```

### 6.2. `useBitcoinAccount` – BTC Address & Balance

Uses Mezo Passport's `useBitcoinAccount()` hook to obtain the Bitcoin address and balance (in satoshis) of the connected wallet. The balance is returned as `{ confirmed: number, unconfirmed: number, total: number }`.

```typescript
// hooks/useBitcoinAccount.ts
'use client';

import { useBitcoinAccount as usePassportBitcoinAccount } from '@mezo-org/passport';
import { useAccount } from 'wagmi';
import { useMemo } from 'react';

interface BitcoinAccount {
  /** Bitcoin address (native BTC) */
  btcAddress: string | undefined;
  /** Balance in satoshis */
  btcBalance: {
    confirmed: number;
    unconfirmed: number;
    total: number;
  };
  /** True if connected via a Bitcoin wallet (Xverse, Unisat, OKX) */
  isBitcoinWallet: boolean;
  /** Underlying Mezo Matsnet EVM address */
  evmAddress: `0x${string}` | undefined;
}

/**
 * Wrapper around `useBitcoinAccount` from @mezo-org/passport.
 *
 * Provides the user's native Bitcoin address and balance,
 * plus the underlying EVM address used for smart‑contract interactions.
 *
 * The underlying EVM account enables standard operations like
 * reading data and interacting with smart contracts, while
 * signing is routed to the Bitcoin wallet itself.
 */
export function useBitcoinAccount(): BitcoinAccount {
  const { btcAddress, btcBalance } = usePassportBitcoinAccount();
  const { address: evmAddress } = useAccount();

  const isBitcoinWallet = useMemo(() => {
    // If btcAddress is present, the user connected via a Bitcoin wallet.
    return typeof btcAddress === 'string' && btcAddress.length > 0;
  }, [btcAddress]);

  return {
    btcAddress,
    btcBalance: btcBalance ?? { confirmed: 0, unconfirmed: 0, total: 0 },
    isBitcoinWallet,
    evmAddress,
  };
}

/**
 * Format satoshis to BTC string.
 * 100,000,000 satoshis = 1 BTC
 */
export function satoshisToBTC(satoshis: number): string {
  return (satoshis / 100_000_000).toFixed(8);
}
```

### 6.3. `useNetworkStatus` – Network Health

Monitors whether the user is on the correct network (Mezo Testnet).

```typescript
// hooks/useNetworkStatus.ts
'use client';

import { useChainId, useSwitchChain } from 'wagmi';
import { useMemo, useCallback } from 'react';
import { mezoTestnet, mezoMainnet } from '@mezo-org/passport';
import { toast } from 'sonner';

interface NetworkStatus {
  /** True if on Mezo Testnet or Mezo Mainnet */
  isCorrectNetwork: boolean;
  /** Current chain name */
  chainName: string | undefined;
  /** True while switching networks */
  isSwitching: boolean;
  /** Switch to Mezo Testnet */
  switchToCorrectNetwork: () => Promise<void>;
}

const SUPPORTED_CHAIN_IDS = new Set([mezoTestnet.id, mezoMainnet.id]);
const CHAIN_NAMES: Record<number, string> = {
  [mezoTestnet.id]: 'Mezo Testnet',
  [mezoMainnet.id]: 'Mezo Mainnet',
};

export function useNetworkStatus(): NetworkStatus {
  const chainId = useChainId();
  const { switchChainAsync, isPending: isSwitching } = useSwitchChain();

  const isCorrectNetwork = useMemo(
    () => SUPPORTED_CHAIN_IDS.has(chainId),
    [chainId]
  );

  const chainName = useMemo(
    () => (chainId ? CHAIN_NAMES[chainId] || `Chain ${chainId}` : undefined),
    [chainId]
  );

  const switchToCorrectNetwork = useCallback(async () => {
    try {
      await switchChainAsync({ chainId: mezoTestnet.id });
      toast.success('Switched to Mezo Testnet');
    } catch (error: any) {
      if (!error?.message?.includes('rejected')) {
        toast.error(`Network switch failed: ${error?.message || 'Unknown error'}`);
      }
    }
  }, [switchChainAsync]);

  return { isCorrectNetwork, chainName, isSwitching, switchToCorrectNetwork };
}
```

### 6.4. `useBitcoinTransaction` – BTC Send & Sign

Uses `useSendBitcoin` for sending native BTC transactions and `useSignMessage` for signing messages.

```typescript
// hooks/useBitcoinTransaction.ts
'use client';

import { useSendBitcoin } from '@mezo-org/passport';
import { useSignMessage } from 'wagmi';
import { useCallback } from 'react';
import { toast } from 'sonner';

interface BitcoinSendParams {
  /** Recipient BTC address */
  to: string;
  /** Amount in satoshis (1 BTC = 100,000,000 satoshis) */
  amountSatoshis: number;
}

/**
 * Hooks for sending BTC and signing messages.
 *
 * - `sendBitcoin` sends native BTC from the connected Bitcoin wallet.
 * - `signMessage` signs an arbitrary message using the connected wallet.
 *
 * Note: `useSendTransaction` from @mezo-org/passport is used for
 * EVM transactions on Mezo Matsnet, while `useSendBitcoin` is used
 * for native Bitcoin transactions.
 */
export function useBitcoinTransaction() {
  const { sendBitcoin, isPending: isSendingBtc } = useSendBitcoin();
  const { signMessageAsync, isPending: isSigning } = useSignMessage();

  /**
   * Send native BTC from the connected Bitcoin wallet.
   *
   * sendBitcoin takes two arguments:
   *  - address: the BTC recipient address
   *  - amount: the amount in satoshis
   */
  const sendBtc = useCallback(
    async ({ to, amountSatoshis }: BitcoinSendParams): Promise<string | null> => {
      try {
        const txHash = await sendBitcoin(to, amountSatoshis);
        toast.success(`BTC sent! Tx: ${txHash?.slice(0, 10)}...`);
        return txHash;
      } catch (error: any) {
        if (error?.message?.includes('rejected') || error?.message?.includes('User rejected')) {
          toast.error('Transaction cancelled.');
        } else {
          toast.error(`BTC send failed: ${error?.message || 'Unknown error'}`);
        }
        return null;
      }
    },
    [sendBitcoin]
  );

  /**
   * Sign a message with the connected wallet.
   * Uses standard wagmi `useSignMessage` hook.
   */
  const signMessage = useCallback(
    async (message: string): Promise<string | null> => {
      try {
        const signature = await signMessageAsync({ message });
        toast.success('Message signed successfully');
        return signature;
      } catch (error: any) {
        if (error?.message?.includes('rejected') || error?.message?.includes('User rejected')) {
          toast.error('Signing cancelled.');
        } else {
          toast.error(`Signing failed: ${error?.message || 'Unknown error'}`);
        }
        return null;
      }
    },
    [signMessageAsync]
  );

  return {
    sendBtc,
    signMessage,
    isSendingBtc,
    isSigning,
  };
}
```

### 7.1. ConnectButton – Styled RainbowKit Button

Mezo Passport supports two ways to connect: via RainbowKit's `ConnectButton` (simplest) or via wagmi's `useConnect` hook (full control). We use the custom approach for maximum design flexibility.

```tsx
// components/wallet/ConnectButton.tsx
'use client';

import { useWalletConnection } from '@/hooks/useWalletConnection';
import { useNetworkStatus } from '@/hooks/useNetworkStatus';
import { useBitcoinAccount } from '@/hooks/useBitcoinAccount';
import { Button } from '@/components/ui/Button';
import { Wallet, AlertCircle, Loader2, ChevronDown, Bitcoin } from 'lucide-react';
import { cn } from '@/lib/utils';
import { useState } from 'react';

/**
 * Custom wallet connection button.
 *
 * Renders differently based on connection state:
 * - Disconnected: "Connect Wallet" CTA
 * - Connecting: loading spinner
 * - Connected (wrong network): "Switch Network" warning
 * - Connected: address + network indicator
 */
export function ConnectButton() {
  const { isConnected, isConnecting, connect, disconnect } = useWalletConnection();
  const { isCorrectNetwork, switchToCorrectNetwork } = useNetworkStatus();
  const { btcAddress, isBitcoinWallet } = useBitcoinAccount();
  const [menuOpen, setMenuOpen] = useState(false);

  // --- Not Connected ---
  if (!isConnected) {
    return (
      <Button onClick={connect} loading={isConnecting} className="gap-2">
        <Wallet className="h-4 w-4" />
        {isConnecting ? 'Connecting…' : 'Connect Wallet'}
      </Button>
    );
  }

  // --- Wrong Network ---
  if (!isCorrectNetwork) {
    return (
      <Button onClick={switchToCorrectNetwork} variant="danger" className="gap-2">
        <AlertCircle className="h-4 w-4" />
        Switch to Mezo
      </Button>
    );
  }

  // --- Connected (correct network) ---
  return (
    <div className="relative">
      <button
        onClick={() => setMenuOpen(!menuOpen)}
        className={cn(
          'flex items-center gap-2 px-4 py-2 rounded-xl border transition',
          'bg-card border-border hover:bg-white/5'
        )}
      >
        {isBitcoinWallet && <Bitcoin className="h-4 w-4 text-mezo-primary" />}
        <span className="text-sm font-medium">
          {btcAddress ? `${btcAddress.slice(0, 6)}…${btcAddress.slice(-4)}` : 'Connected'}
        </span>
        <div className="w-2 h-2 rounded-full bg-mezo-accent" />
        <ChevronDown className="h-4 w-4 text-mezo-muted" />
      </button>

      {/* Dropdown */}
      {menuOpen && (
        <div
          className="absolute right-0 mt-2 w-56 rounded-xl bg-mezo-darker border border-border shadow-xl z-50"
          onMouseLeave={() => setMenuOpen(false)}
        >
          <div className="p-3 border-b border-border">
            <p className="text-xs text-mezo-muted">
```

### 7.4. WalletErrorBoundary – Connection Recovery

```tsx
// components/wallet/WalletErrorBoundary.tsx
'use client';

import { Component, type ErrorInfo, type ReactNode } from 'react';
import { Button } from '@/components/ui/Button';
import { AlertTriangle, RefreshCw } from 'lucide-react';

interface Props {
  children: ReactNode;
  onReset?: () => void;
}

interface State {
  hasError: boolean;
  error: Error | null;
}

export class WalletErrorBoundary extends Component<Props, State> {
  constructor(props: Props) {
    super(props);
    this.state = { hasError: false, error: null };
  }

  static getDerivedStateFromError(error: Error): Partial<State> {
    return { hasError: true, error };
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    console.error('[WalletErrorBoundary] Wallet connection error:', error, errorInfo);
  }

  handleReset = () => {
    this.props.onReset?.();
    this.setState({ hasError: false, error: null });
    window.location.reload();
  };

  render() {
    if (this.state.hasError) {
      return (
        <div className="fixed inset-0 flex items-center justify-center bg-mezo-darker/95 backdrop-blur-sm z-50">
          <div className="max-w-md p-8 bg-card border border-border rounded-2xl text-center">
            <AlertTriangle className="h-16 w-16 text-mezo-primary mx-auto mb-4" />
            <h2 className="text-xl font-bold mb-2">Wallet Connection Error</h2>
            <p className="text-mezo-muted mb-6">
              {this.state.error?.message || 'An unexpected error occurred with your wallet.'}
            </p>
            <Button onClick={this.handleReset} className="gap-2">
              <RefreshCw className="h-4 w-4" />
              Reset Connection
            </Button>
          </div>
        </div>
      );
    }

    return this.props.children;
  }
}
```

## 8. Utility Helpers

### 8.1. Wallet Error Parser

```typescript
// lib/wallet/errors.ts
export enum WalletErrorType {
  CONNECTOR_NOT_FOUND = 'ConnectorNotFoundError',
  USER_REJECTED = 'UserRejectedRequestError',
  CHAIN_NOT_CONFIGURED = 'ChainNotConfiguredError',
  NETWORK_ERROR = 'NetworkError',
  UNSUPPORTED_CHAIN = 'UnsupportedChainError',
  INSUFFICIENT_FUNDS = 'InsufficientFundsError',
  UNKNOWN = 'UnknownError',
}

export interface ParsedWalletError {
  type: WalletErrorType;
  message: string;
  originalError?: Error;
}

export function parseWalletError(error: unknown): ParsedWalletError {
  const msg = error instanceof Error ? error.message : String(error);
  const name = error instanceof Error ? error.name : '';

  if (msg.includes('User rejected') || msg.includes('user rejected')) {
    return { type: WalletErrorType.USER_REJECTED, message: 'Transaction was rejected by the user.' };
  }
  if (name === 'ConnectorNotFoundError' || msg.includes('Connector not found')) {
    return {
      type: WalletErrorType.CONNECTOR_NOT_FOUND,
      message: 'Wallet not found. Please install Xverse, Unisat, OKX, or MetaMask.',
    };
  }
  if (msg.includes('Chain mismatch') || name === 'ChainMismatchError') {
    return { type: WalletErrorType.CHAIN_NOT_CONFIGURED, message: 'Please switch to Mezo Testnet.' };
  }
  if (msg.includes('insufficient funds')) {
    return { type: WalletErrorType.INSUFFICIENT_FUNDS, message: 'Insufficient BTC for gas fees.' };
  }
  return { type: WalletErrorType.UNKNOWN, message: msg || 'An unknown error occurred.' };
}
```

```typescript
// lib/utils/address.ts
export function shortenAddress(address: string, chars = 4): string {
  if (!address || address.length < chars * 2 + 4) return address || '';
  return `${address.slice(0, chars + 2)}…${address.slice(-chars)}`;
}

export function formatBTCAddress(address: string): string {
  if (address.startsWith('bc1')) {
    return `${address.slice(0, 8)}…${address.slice(-6)}`;
  }
  return shortenAddress(address, 5);
}
```
