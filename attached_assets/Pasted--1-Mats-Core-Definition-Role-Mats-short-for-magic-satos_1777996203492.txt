## 1. Mats Core Definition & Role

Mats, short for "magic satoshis," are Mezo's native off-chain points system designed to recognize and reward user activity across the entire ecosystem. While they hold no direct monetary value, they function as a critical activity metric that directly influences future MEZO token allocations and unlocks access to various ecosystem features.

The core purpose of Mats is to replace superficial one-time wallet checks with a dynamic, behavior-based reward system. Mezo explicitly "rewards activity through mats rather than one-time wallet checks," ensuring that genuine, sustained engagement drives reward distribution. Participation can range "from simple quests to deeper onchain interaction," providing multiple entry points for users with varying levels of commitment.

From a technical perspective, Mats serve three primary functions:
- **Activity Measurement**: Mats function as "activity points that measure user participation across the Mezo ecosystem"
- **Airdrop Determination**: A user's Mats balance "determines your allocation eligibility for the MEZO airdrop"
- **Ecosystem Access**: Mats unlock access to testnet features and can be converted into functional testnet assets

## 2. Mats Earning Mechanisms

### 2.1. On-Chain Financial Activity

The most impactful way to earn Mats is through verifiable on-chain financial participation. Mezo's "Statement" query feature allows users to view their transaction volume across Bitcoin and EVM chains, with Mats rewards scaling based on on-chain activity. Key earning actions include:

- **Asset Deposits**: Users can "Earn mats by depositing BTC, tBTC, WBTC, or any of the 10+ other assets" supported by Mezo, including stablecoins
- **Borrowing MUSD**: "Borrowing MUSD against Bitcoin" generates Mats proportional to loan size and duration
- **Liquidity Provision**: Providing liquidity to DEX pools and vaults earns ongoing Mats rewards
- **Vault Participation**: Depositing into yield-generating vaults like the BTC Vault on Upshift earns Mats, with "100,000 mats distributed daily to vault depositors based on their share of the total vault TVL"

The Statement query functionality specifically allows users to "view their transaction volume on Bitcoin (BTC) and EVM chains and unlock Mats point rewards based on on-chain activity," with additional multipliers available through "social sharing and on-chain interaction tasks".

### 2.2. Community & Social Engagement

Beyond pure financial activity, Mezo has built an extensive Discord-native Mats economy that rewards community participation. Users can earn Mats through:

- **Meme Market**: "Expand your mats holdings by creating memes in the Discord-native mats Meme Market and trading them"
- **Quests & Bounties**: "Create quests or complete quests for mats rewards"
- **Games**: "Poker, coin flip, rocket game, and more"
- **Lootbox**: "Claim up to 250 mats just for showing up. That's equal to 20k worth of stables deposited into Mezo!"
- **Bounty Board**: A "mats Bounty Board" enables users to post or claim specific bounties for completing more involved tasks, creating a "new landscape of possibilities extending far beyond Discord activity"

### 2.3. Testnet Participation

Mats earned during the pre-mainnet phase transitioned from testnet points to real on-chain rewards. Through matsnet Alpha, Mezo's incentivized testnet, users could "convert their mats into matsnet BTC and explore the testnet's capabilities, from dApps to leaderboard challenges". This created a "reward loop" where users could expand their Mats holdings through community activities, then convert Mats into testnet BTC to participate in the BitcoinFi ecosystem.

The "Stack Rank" leaderboard tracked activity on matsnet, and converting Mats to testnet BTC affected standings on the original Mats leaderboard, creating strategic trade-offs that encouraged deeper ecosystem engagement.

### 2.4. Mainnet Mats

With mainnet live, Mats have entered a new phase. "Mainnet mats are distinct from Testnet mats" and "the supply of Mainnet mats are extremely limited, and as such, will be rewarded more favorably compared to Testnet mats". This tiered approach ensures that post-launch activity carries higher weight than pre-launch participation, incentivizing sustained engagement.

The BTC Vault on Upshift represents the "first and most prominent way to earn Mainnet mats," with new features like Tigris (Mezo's native DEX), ecosystem apps (Velar, ZeroLend, BitFi), and Mezo Earn unlocking broader earning opportunities.

## 3. Mats Distribution Architecture

### 3.1. Two-Season Structure

The Mats distribution system operated across two distinct seasons with dramatically different exchange rates:

| Season | Timeframe | Exchange Rate | Significance |
|:---|:---|:---|:---|
| **Season 1** | March 2024 – May 2025 | 1 MEZO = 679.9 mats | Early adopter premium; high Mats generation |
| **Season 2** | May 2025 – January 2026 | 1 MEZO = 36.78 mats | Scaled-down rewards; increasing scarcity |

This steep reduction in the exchange rate (approximately 18.5x less favorable in Season 2) reflects a deliberate strategy to reward the earliest participants most generously. Addresses that participated in both seasons received an additional **25% basic distribution bonus**.

### 3.2. Snapshot & Mainnet Transition

At mainnet launch, all Mats earned from pre-mainnet sources stopped accruing. The snapshot captured users' total Mats balances, which continued to be tracked in Mezo wallets alongside new Mainnet Mats earned through on-chain activity. The official guidance stated: "All mats earned—from deposits, referrals, community activities, matsnet transactions—stop accruing at mainnet launch... Your mats balance will be included in the snapshot and you'll be ready to earn on mainnet".

This transition marked "the end of the matsnet phase," after which "testnet activities will not earn mats or other incentives".

### 3.3. Phase 1 Airdrop Allocation

The Phase 1 MEZO token distribution, announced in January 2026, provided the first concrete link between Mats and actual token rewards. Key metrics include:

- **Total Community Airdrop**: 5% of total MEZO supply (50 million MEZO)
- **Phase 1 Allocation**: Approximately 2% of total supply (19,824,782 MEZO)
- **Eligible Addresses**: 11,845 addresses (from over 100,000 registered users)
- **Minimum Claim Threshold**: 60 MEZO
- **veMEZO Lock Rate**: 13% of eligible addresses chose to lock their allocation as veMEZO

The distribution weight emphasized "ongoing on-chain activities such as cross-chain transfers to the mainnet, asset swaps, lending, providing liquidity, participating in vaults, and veBTC-related activities".

### 3.4. The "Mats Do Not Guarantee Rewards" Principle

Importantly, "Mats influence eligibility and potential allocation but do not guarantee rewards". This design prevents gaming and ensures that distribution considers multiple factors beyond raw point accumulation. The system is designed to reward "real usage retroactively" rather than superficial engagement, with "the more value and time committed, the higher the reward weighting".

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.19;

import "@openzeppelin/contracts/access/Ownable.sol";
import "@openzeppelin/contracts/utils/math/SafeMath.sol";

contract MatsTracker is Ownable {
    using SafeMath for uint256;
    
    struct UserActivity {
        uint256 deposits;           // veMEZO NFT deposits
        uint256 compounds;          // Auto-compound calls
        uint256 lockExtensions;     // Lock duration increases
        uint256 shareDays;          // Vault shares held (days)
        uint256 totalMats;          // Calculated Mats score
        uint256 updatedAt;
    }
    
    mapping(address => UserActivity) public userActivity;
    mapping(address => address) public referrals;  // User → referrer
    
    uint256 public constant DEPOSIT_MATS = 500;        // Per NFT deposit
    uint256 public constant COMPOUND_MATS = 100;       // Per compound cycle
    uint256 public constant LOCK_EXTENSION_MATS = 250; // Per extension
    uint256 public constant SHARE_DAY_MATS = 1;        // Per share per day
    uint256 public constant REFERRAL_BONUS = 50;       // 5% of referred user Mats
    
    address public matsOracle;  // Off-chain oracle for Discord/social Mats
    uint256 public totalMatsDistributed;
    
    event MatsEarned(address indexed user, uint256 amount, string activityType);
    event ReferralBonus(address indexed referrer, address indexed referred, uint256 amount);
    
    modifier onlyOracleOrKeeper() {
        require(msg.sender == matsOracle || msg.sender == owner(), "Unauthorized");
        _;
    }
    
    function recordDeposit(address user, uint256 tokenId) external onlyOracleOrKeeper {
        userActivity[user].deposits = userActivity[user].deposits.add(1);
        uint256 mats = DEPOSIT_MATS;
        _mintMats(user, mats, "deposit");
        
        // Referral bonus
        address referrer = referrals[user];
        if (referrer != address(0)) {
            uint256 bonus = mats.mul(REFERRAL_BONUS).div(1000); // 5%
            _mintMats(referrer, bonus, "referral");
            emit ReferralBonus(referrer, user, bonus);
        }
    }
    
    function recordCompound(address user) external onlyOracleOrKeeper {
        userActivity[user].compounds = userActivity[user].compounds.add(1);
        uint256 mats = COMPOUND_MATS;
        _mintMats(user, mats, "compound");
    }
    
    function recordLockExtension(address user) external onlyOracleOrKeeper {
        userActivity[user].lockExtensions = userActivity[user].lockExtensions.add(1);
        uint256 mats = LOCK_EXTENSION_MATS;
        _mintMats(user, mats, "lock_extension");
    }
    
    function updateShareDays(address user, uint256 days) external onlyOracleOrKeeper {
        uint256 mats = days.mul(SHARE_DAY_MATS);
        userActivity[user].shareDays = userActivity[user].shareDays.add(days);
        _mintMats(user, mats, "share_days");
    }
    
    function importSocialMats(address user, uint256 amount) external onlyOwner {
        // Import Discord/quest Mats from off-chain oracle
        _mintMats(user, amount, "social");
    }
    
    function _mintMats(address user, uint256 amount, string memory activityType) internal {
        userActivity[user].totalMats = userActivity[user].totalMats.add(amount);
        userActivity[user].updatedAt = block.timestamp;
        totalMatsDistributed = totalMatsDistributed.add(amount);
        emit MatsEarned(user, amount, activityType);
    }
    
    function setReferral(address user, address referrer) external onlyOwner {
        require(referrals[user] == address(0), "Referral already set");
        referrals[user] = referrer;
    }
    
    function getEligibilityScore(address user) external view returns (uint256) {
        UserActivity memory activity = userActivity[user];
        // Season 2 multiplier: 36.78 mats per MEZO equivalent
        return activity.totalMats.mul(3678).div(10000);
    }
}

🔗 4. Mats Hooks + Integration
hooks/useMatsBalance.ts
ts
"use client";

import { useAccount } from "wagmi";
import { useQuery } from "@tanstack/react-query";
import { MATS_TRACKER_ADDRESS, MATS_ABI } from "@/lib/contracts";

export function useMatsBalance() {
  const { address } = useAccount();

  return useQuery({
    queryKey: ["matsBalance", address],
    queryFn: async () => {
      if (!address) return null;
      
      const totalMats = await readContract({
        address: MATS_TRACKER_ADDRESS,
        abi: MATS_ABI,
        functionName: "userActivity",
        args: [address],
      });
      
      const eligibility = await readContract({
        address: MATS_TRACKER_ADDRESS,
        abi: MATS_ABI,
        functionName: "getEligibilityScore",
        args: [address],
      });
      
      return {
        total: Number(totalMats.totalMats),
        deposits: Number(totalMats.deposits),
        compounds: Number(totalMats.compounds),
        eligibility: { score: Number(eligibility) },
      };
    },
    enabled: !!address,
    refetchInterval: 30000,
  });
}

export function useMatsEligibility() {
  const { address } = useAccount();
  
  return useQuery({
    queryKey: ["matsEligibility", address],
    queryFn: async () => ({
      eligible: true,
      score: 125680,
      bonus: "25% Season 2",
      phase: "Phase 1 Complete",
    }),
    enabled: !!address,
  });
}
